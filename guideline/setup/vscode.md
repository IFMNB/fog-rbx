# Visual Studio Code

Для разработки проекта рекомендуется использовать **Visual Studio Code**. Проект ориентирован на работу с `Luau Language Server` и `StyLua`.

## Luau Language Server

`Luau Language Server` используется для анализа кода, проверки типов и навигации по проекту. Он удобен, поскольку иначе без него было бы невозможно иметь навигацию по проекту.

После открытия проекта убедитесь, что сервер языка успешно запущен и не сообщает об отсутствии зависимостей. При корректной настройке должны работать:

* переход к определению (`Go to Definition`);
* поиск всех использований (`Find References`);
* автодополнение;
* проверка типов;
* отображение документации.

Все предупреждения `Luau Language Server`, связанные с ошибками типов, считаются ошибками кода и должны устраняться до отправки изменений. Обязательно, чтобы в `--!strict` режиме исполнения код не отображался с ошибками.

При использовании собственного рабочего окружения допускается изменение пользовательских настроек редактора, однако настройки рабочей области проекта изменять не следует.

## StyLua

Для форматирования исходного кода используется `StyLua`.

Перед публикацией изменений рекомендуется выполнить форматирование всех измененных файлов.

## Extensions

Для работы над проектом рекомендуется установить следующие расширения:

* Luau Language Server
* StyLua

Использование дополнительных расширений остается на усмотрение разработчика.

## Workspace

Настройки рабочей области находятся внутри директории `.vscode` и являются частью проекта.

Не следует изменять существующие настройки без необходимости, так как они обеспечивают единое окружение разработки для всех участников команды.

Если для собственного рабочего процесса требуется изменить параметры редактора, рекомендуется использовать пользовательские настройки Visual Studio Code (`User Settings`), а не настройки рабочей области.

## Formatting

Исходный код проекта должен сохранять единый стиль оформления независимо от автора изменений.

Перед созданием `commit` рекомендуется убедиться, что все измененные файлы были успешно проверены `Luau Language Server` и отформатированы `StyLua`.

Изменения, содержащие исключительно форматирование существующего кода, рекомендуется выполнять отдельным обновлением, не смешивая их с функциональными изменениями.

# Toolchain

## General

Для обеспечения одинаковой среды разработки между всеми участниками проекта используется менеджер инструментов (`toolchain manager`). Все версии утилит фиксируются внутри репозитория и не должны зависеть от глобально установленных программ.

Перед началом работы убедитесь, что на вашей системе установлен хотя бы один поддерживаемый менеджер инструментов. В проекте уже присутствуют необходимые конфигурационные файлы для:

* `Foreman`
* `Rokit`
* `Aftman`

Используйте любой из перечисленных менеджеров.

Не рекомендуется использовать глобально установленные версии утилит при работе с проектом. Все инструменты должны запускаться через выбранный менеджер.

## Installation

После клонирования репозитория перейдите в его корневую директорию и установите все необходимые инструменты при помощи выбранного вами менеджера.

Конфигурационные файлы уже содержат необходимые версии всех зависимостей. Их ручное изменение не требуется.

При обновлении репозитория рекомендуется повторно выполнить установку инструментов, если были изменены соответствующие конфигурационные файлы.

## Versions

Версии всех инструментов являются частью проекта.

Если вы обнаружили более новую версию какой-либо утилиты, не обновляйте ее самостоятельно. Изменение версий производится только в рамках отдельного обновления проекта после согласования с остальными участниками разработки.

Все разработчики должны использовать одинаковые версии инструментов.

## Adding tools

Если во время разработки возникла необходимость добавить новый инструмент, сначала следует обсудить это с остальными участниками проекта. Не добавляйте зависимости только для собственного окружения.

## PATH

После установки инструментов убедитесь, что выбранный менеджер корректно настроил переменную окружения `PATH`.

Если инструмент недоступен после установки, сначала проверьте настройку менеджера инструментов, а затем повторите установку.

Не рекомендуется вручную копировать исполняемые файлы в системные директории.

## Updates

При изменении конфигурации `Foreman`, `Rokit` или `Aftman` соответствующие изменения должны попасть в репозиторий вместе с остальным кодом.

Изменения конфигурации менеджеров инструментов рассматриваются как часть проекта и проходят тот же процесс проверки, что и остальные изменения кодовой базы.


# Usage

## Foreman

```
    Foreman
    foreman install

    После этого инструменты станут доступны через:

    foreman run rojo serve
    foreman run stylua .

    или напрямую, если PATH настроен Foreman.
```

## Aftman

```
    aftman install

    После установки инструменты доступны через PATH:

    rojo serve
    stylua .

    При необходимости можно проверить установку:

    aftman list
```

## Rokit

```

    rokit install

    Запуск инструментов:

    rokit run rojo serve
    rokit run stylua .
```

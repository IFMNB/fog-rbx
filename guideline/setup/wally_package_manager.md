# Wally

## General

Для управления зависимостями проекта используется `Wally`. Все библиотеки, используемые проектом, описываются в файле `wally.toml`.

Не добавляйте зависимости вручную в файловую систему проекта. Все библиотеки должны устанавливаться исключительно через `Wally`.

Если требуемая библиотека отсутствует, сначала согласуйте ее добавление с остальными участниками разработки.

## Installation

После клонирования репозитория перейдите в его корневую директорию и выполните установку всех зависимостей.

```
wally install
```

Все библиотеки будут автоматически загружены в директорию, используемую проектом.

При изменении файла `wally.toml` рекомендуется повторно выполнить установку зависимостей.

## Usage

После изменения списка зависимостей выполните повторную установку.

```
wally install
```

Для обновления файла блокировки зависимостей можно воспользоваться командой:

```
wally update
```

При необходимости поиска новой библиотеки используйте:

```
wally search <название>
```

## Dependencies

Все используемые библиотеки должны быть перечислены в `wally.toml`.

Не изменяйте версии существующих зависимостей без необходимости.

Не удаляйте и не добавляйте библиотеки, не относящиеся к вашей задаче.

## Updates

Изменения файла `wally.toml` должны попадать в репозиторий вместе с остальным кодом.

Если изменение зависимостей влияет на работу публичного API проекта, оно должно быть предварительно согласовано с остальными участниками разработки.

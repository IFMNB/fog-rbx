# Rojo

## General

Весь проект синхронизируется с Roblox Studio при помощи `rojo`. Любые изменения структуры проекта должны производиться через файловую систему, а не через Explorer внутри Studio. Studio рассматривается исключительно как среда тестирования и просмотра результатов.

Основным конфигурационным файлом является `default.project.json`, находящийся в корне репозитория. Любые изменения дерева экземпляров должны сопровождаться изменениями этого файла.

Если вы не уверены, куда должен располагаться новый код, посмотрите существующую структуру проекта в `./src/`.

## Synchronization

Перед открытием проекта необходимо запустить сервер синхронизации.

```bash
rojo serve
```

После запуска необходимо открыть `.rbxl` или `.rbxlx` файл проекта и подключиться к серверу через плагин Rojo. Для конкретной версии Rojo его можно скачать с Github Releases как файл `.rbxm` и встроить в свои плагины.

После успешного подключения любые изменения файлов внутри проекта будут автоматически синхронизироваться со Studio.

Если синхронизация была потеряна, рекомендуется перезапустить `rojo serve` и переподключить проект.

## Workspace

Не создавайте объекты через Explorer, если они должны существовать в репозитории.

Любые экземпляры, являющиеся частью проекта, должны существовать как файлы внутри `./src/`. Исключением являются временные объекты, необходимые исключительно для тестирования.

При необходимости изменить структуру проекта следует изменять файловую систему, а не дерево объектов внутри Studio, если вы хотите сохранить свои правки. Правки внутри Studio, которые вы вносите для целей не связанных с проектом, - делайте с ними что и как угодно.

## Packages

Если используется менеджер зависимостей, то автоматически сгенерированные каталоги не должны изменяться вручную.

Любые изменения зависимостей производятся средствами соответствующего пакетного менеджера. Содержимое автоматически сгенерированных директорий не редактируется.

## Project

При добавлении нового сервиса, папки или объекта необходимо убедиться, что он корректно отображается в `default.project.json`.

Если после запуска `rojo serve` изменения не появились в Studio, следует проверить корректность путей внутри конфигурации проекта и вашего Rojo. При необходимости обратитесь за помощью.

## Studio

Roblox Studio не является источником истины для содержимого проекта.

Все изменения, которые должны попасть в систему контроля версий, производятся исключительно через файловую систему. Любые изменения, сделанные только внутри Studio, могут быть потеряны после следующей синхронизации.

## Github

Перед созданием коммита рекомендуется убедиться, что:

* отсутствуют временные объекты и тестовые файлы;
* синхронизация завершилась без ошибок;
* изменения соответствуют структуре проекта;
* `default.project.json` содержит актуальную конфигурацию при изменении дерева экземпляров.

Не добавляйте в репозиторий временные файлы Roblox Studio, автоматически созданные конфигурации редакторов, локальные настройки разработки и лишний мусор, если они не используются всей командой.

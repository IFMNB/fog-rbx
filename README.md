# ForgottenGrave

Последние технические исходники игры. Гарантий совпадения с текущим релизом в игре нет, они могут отличаться.

# Dependencies

Перед началом работы повысьте свои лимиты для типизации. Это требуется, потому что уровень сложности типов для проекта превышает стандартные лимиты LuauSL, - константные значения из `/Analysis/src/TypeInfer.cpp`. 

```json
    "luau-lsp.fflags.override": {
        "LuauTypeInferIterationLimit": "35000",
        "LuauTypeInferRecursionLimit": "500",
        "LuauTypeInferTypePackLoopLimit": "10000",
        "LuauCheckRecursionLimit": "1000",
        "LuauVisitRecursionLimit": "1000"
    },
```

# FAQ


> A: Я нашел баг, как я должен о нем сообщить?
> B: Отправить репорт в issues

> A: Я хочу вступить в команду, как я могу это сделать?
> B: Обратитесь на сервер сообщества

> A: Я реализовал что-то прикольное и хочу предложить добавить это в игру, куда мне направить свое предложение?
> B: PR, учтем на upstream при одобрении. Изменения ядра не принимаются, по этому вопросу в Issues

> A: Каково отношение к стороннему контенту по игре, в том числе копиях, фангейму и т.д?
> B: Положительное.

> А: Добавление своего контента в игру?
> B: `Одобренный контент будет оставаться в игре до самого ее конца`, независимо от решения владельца контента после. __Это обязательное условие добавления__.

> A: Каково отношение к читерам?
> B: В основном отрицательное. Если потребуется, игра может значительно пожертвовать комфортом игрока взамен на отсутствие читеров. Поощряется отловка читеров даже из других игр. Не отсылайте репорты в issues, пишите на сервер сообщества
